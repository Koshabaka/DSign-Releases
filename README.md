# DSign — установщики и обновления

DSign создаёт и проверяет отделённые электронные подписи документов в Windows через КриптоПро CSP. Поддерживает один документ и пакет файлов. Результат: `Документ.pdf.sig` рядом с исходным файлом либо в выбранной папке.

**[Скачать DSign](https://github.com/Koshabaka/DSign-Releases/releases)**

Нужны Windows 11 x64, КриптоПро CSP 5.0+ с действующей лицензией, КриптоПро ЭЦП Browser plug-in с 64-битными компонентами и драйверы Рутокен. Среда .NET включена в установщик.

Установщик создаёт ярлык **«Подписать электронный документ»** на рабочем столе и DSign в меню «Пуск».

Начиная с beta.5 приложение автоматически проверяет новые выпуски, скачивает и проверяет пакет, устанавливает его после закрытия DSign. Для перехода с более ранней версии один раз установите beta.5 вручную. Обновления можно выключить в настройках. Вход в GitHub для скачивания и обновлений не нужен.

Автор: **Чубов Андрей Юрьевич**, управляющий партнер, адвокат Московской коллегии адвокатов **«Коляда, Чубов и партнеры»**. [Сайт МКА](https://kc-law.ru/).

В этом репозитории размещены установщики, контрольные суммы, подписанный манифест обновлений и пользовательские инструкции. Исходный код хранится отдельно в закрытом репозитории. Публичный доступ к установщику не означает предоставления открытой лицензии на исходный код.

Документы, PIN и закрытые ключи пользователей не передаются через канал обновлений. Ключ подписи обновлений отличается от ключа электронной подписи на Рутокен. Подпись манифеста не является Authenticode-подписью EXE; такая подпись пока не настроена.

Предварительный выпуск для автора и коллег МКА. Проверка на физическом Рутокен Lite выполнена на нейтральных файлах; приём документов в личных кабинетах судебных площадок отдельно не испытывался.
