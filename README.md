# DSign

**Приложение для подписания документов электронной подписью в Windows.** Работает через КриптоПро CSP и Рутокен Lite, поддерживает отдельные документы и пакет файлов.

## Скачать

**[Скачать установщик DSign](https://github.com/Koshabaka/DSign-Releases/releases)**

Вход в GitHub для скачивания и обновлений не требуется. Установка выполняется для текущего пользователя Windows. Ярлык на рабочем столе — **«Подписать электронный документ»**, со значком МКА.

## Возможности

- Подписание одного документа или пакета файлов.
- Отдельная подпись рядом с документом: `Документ.pdf` → `Документ.pdf.sig`.
- Проверка подписи и соответствия исходному файлу.
- Сохранение исходных документов и защита готовых подписей от перезаписи.
- Автоматическое получение проверенных обновлений после закрытия приложения.

## Что требуется

Windows 11 x64, лицензированный КриптоПро CSP 5.0+, КриптоПро ЭЦП Browser plug-in с 64-битными компонентами и драйверы Рутокен. Среда .NET включена в установщик.
