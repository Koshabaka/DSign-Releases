# DSign

**Приложение для подписания документов электронной подписью в Windows.** Работает через КриптоПро CSP и Рутокен Lite, поддерживает отдельные документы и пакет файлов.

## Скачать

**[Скачать установщик DSign](https://github.com/Koshabaka/DSign-Releases/releases)**

Вход в GitHub для скачивания и обновлений не требуется. Установка выполняется для текущего пользователя Windows. Ярлык на рабочем столе — **«Подписать электронный документ»**, со значком щита, документа и пера.

## Возможности

- Подписание одного документа или пакета файлов.
- Все страницы в корпоративном стиле МКА: фиолетовая палитра, золотые акценты и официальный логотип.
- Сохраняемый сертификат по умолчанию, трей и настраиваемый автозапуск.
- Две отдельные строки основного меню Windows 11: «Подписать документ» и «Подписать без открытия окна»; проверка .sig в меню Проводника.
- Отдельно включаемое подписание без основного окна со штатным PIN КриптоПро.
- Локальная история, повтор ошибок и копирование готовой пары файлов.
- Отдельная подпись рядом с документом: `Документ.pdf` → `Документ.pdf.sig`.
- Проверка подписи и соответствия исходному файлу.
- Сохранение исходных документов и защита готовых подписей от перезаписи.
- Автоматическое получение проверенных обновлений после закрытия приложения.

## Что требуется

Windows 11 x64, лицензированный КриптоПро CSP 5.0+, КриптоПро ЭЦП Browser plug-in с 64-битными компонентами и драйверы Рутокен. Среда .NET включена в установщик.

## Первое включение команд Проводника

Откройте «Настройки», включите команды Проводника и нажмите «Установить команды основного меню». Для отдельного сертификата издателя компонентов потребуется разрешение администратора: открытый сертификат добавляется в «Доверенные лица» компьютера и действует для всех его учётных записей. Корневое хранилище не меняется. Команды DSign регистрируются для текущего пользователя.

Для подписания без основного окна дополнительно выберите свой сертификат документов по умолчанию и разрешите фоновый режим. PIN при необходимости запросит КриптоПро.
